# BATTARI

システム開発実習で作る、BLEすれ違いでステッカーを交換するアプリ。

## ドキュメント（`docs/`）

| ファイル | 内容 |
| --- | --- |
| `00企画書_田中渓都.docx` | 企画書 |
| `01_画面設計書(画面一覧・画面遷移図)_田中渓都.xlsx` | 画面一覧・画面遷移図（v1.1） |
| `02_画面設計書(画面レイアウト)_田中渓都.xlsx` | 画面レイアウト（v1.1） |
| `03_データベース設計書_田中渓都.xlsx` | E-R図・CRUD図・テーブル定義（v1.1） |
| `システム構成図_v1.2.drawio` / `.png` | システム構成図 |

`build01〜03.py` は授業で配布された設計書テンプレートを `~/Downloads/` から読み込む。テンプレートはこのリポジトリに含めていない。
